# SLICE-08：管理后台补全：角色、邀请码与看板

## 声明

- **实现需求**：REQ-034, REQ-035, REQ-044
- **实现架构**：ARCH-009, ARCH-032, ARCH-039
- **拥有路径**：`app/admin/`, `components/admin/`, `lib/admin/`（如需提取前端 helper）
- **消费接口**：`GET/POST/PATCH /api/admin/roles`、`GET/POST/PATCH /api/admin/invite-codes`、`GET /api/admin/users`、`PATCH /api/admin/users/:id/role`、`GET /api/admin/dashboard`
- **产出接口**：无新增后端接口；产出后台前端管理入口
- **依赖切片**：SLICE-01, SLICE-07

## 目标

把 SLICE-01 已提供的管理 API 变成管理员可直接操作的后台入口，补齐角色、邀请码、用户角色和后台首页看板的前端闭环。完成后，REQ-034、REQ-035、REQ-044 不再依赖手工调用 API、手填 `roleId` 或只看接口返回。

## 任务

### 1. 后台首页看板

- 在 `/admin` 首屏展示精简看板摘要：课程完成率、测评通过率、阶段考核通过率。
- 消费 `GET /api/admin/dashboard`，按现有返回结构展示学员明细入口。
- 空数据、加载中和错误态要可见，不允许静默失败。
- 首版不做 BI 报表、复杂筛选器或图表库；优先用简洁表格和指标块。

### 2. 角色管理

- 在后台提供角色列表和创建/编辑表单。
- 支持维护角色 `code`、`name`、`isAdmin` 等现有 API 字段。
- 保存后刷新角色列表，并同步影响用户角色下拉选项。
- 不新增组织树、部门、岗位层级或多租户配置。

### 3. 邀请码管理

- 在后台提供邀请码列表和创建/更新表单。
- 支持选择绑定角色、启用/停用、设置过期时间。
- 邀请码明文只按后端安全约束展示；列表不得假设数据库保存明文 code。
- 保存后刷新列表，并清楚展示邀请码状态、绑定角色和过期时间。

### 4. 用户角色管理升级

- 将用户当前角色修改从手填 `roleId` 升级为角色下拉选择。
- 用户列表加载时同时加载角色列表，展示角色名称和标识。
- 角色修改成功后刷新用户列表；失败时保留原状态并提示错误。

### 5. 后台页面组织

- 保持单页轻量后台，不引入复杂侧边栏。
- 页面分区顺序建议为：看板、角色、邀请码、用户、课程。
- 复用现有 OpenMAIC 风格和已存在 `components/admin/` 组件模式。

### 6. 测试与验收

- 覆盖后台前端 helper 或组件的核心状态映射：加载、空数据、错误、保存成功。
- 覆盖用户角色下拉使用角色列表，而不是自由输入 `roleId`。
- 若修改 API 调用层，补充对应单元测试；已有路由权限测试不可删除。
- 提交前跑通测试与 lint。

## 完成标准

- 管理员可从后台创建/编辑角色。
- 管理员可从后台创建、停用/启用并更新邀请码过期时间和绑定角色。
- 管理员可在后台首页看到课程完成率、测评通过率、阶段考核通过率和学员明细入口。
- 管理员修改用户角色时使用角色下拉选择，不再依赖手填 `roleId`。
- 不新增后端 API，不扩大到组织架构、多租户后台或复杂 BI 报表。
