## 切片生成约束

切片生成阶段必须维护 REQ 覆盖矩阵，至少包含：REQ-ID、用户可见入口、后端/API 契约、权限边界、测试/验收方式、所属 SLICE、是否 API-only。凡 PRD 写有“管理员可 / 学员可 / 后台展示 / 用户看到”的需求，默认必须有前端入口；若某切片只完成 API，必须标记 API-only，并指定后续 UI 切片。

## 集成检查点

1. **SLICE-00 完成后**：数据库 schema、会话 token、API Key 校验、origin/CSP 配置可编译并有单元测试。
2. **SLICE-07 完成后**：学员可用手机号+密码+邀请码注册；宿主 `hostUserId` 可自动绑定管理员；管理员看到后台入口。
3. **SLICE-01 完成后**：后端 CRUD、课程可见过滤、后台看板 API、宿主查询 API 可用；角色/邀请码/看板前端入口仍由 SLICE-08 补齐。
4. **SLICE-08 完成后**：管理员可在后台首页查看精简看板，可用表单维护角色、邀请码和用户当前角色，不再依赖手填 `roleId` 或直接调用 API。
5. **SLICE-03 完成后**：管理员可生成课程、默认进入大纲确认、发布课程并设置全体/角色可见；学员课程列表过滤正确。
6. **SLICE-04 完成后**：课程完成后进入课后测评；失败必须重学；每次测评尝试落库。
7. **SLICE-05 完成后**：管理员可发布阶段考核；学员可参加；只抽单选/多选并记录结果。
8. **SLICE-02 + SLICE-06 完成后**：嵌入入口、postMessage 即时通知、IndexedDB 缓存/弱网恢复不破坏权威后端流程。
9. **SLICE-09 完成后**：管理员首页保持生成工作台；学员首页只显示企业/本地课程和角色考核，且本地课程与企业数据严格隔离。
10. **全链路验收**：宿主 SSO 进入管理员 → 创建邀请码/角色/分类 → 生成发布课程 → 学员注册学习 → 测评/考核 → OpenMAIC 看板和宿主查询 API 展示数据。
